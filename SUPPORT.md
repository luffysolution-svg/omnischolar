# Support

OmniScholar is an open-source project without a support SLA.

- GitHub Issues: <https://github.com/luffysolution-svg/omnischolar/issues>
- Email: `LuffySolution@gmail.com`

When reporting a problem, include the OmniScholar version, operating system, Agent, command or tool name, and the error code. A small example configuration is useful, but replace API keys, tokens, signed URLs, private paths, paper content, Zotero records, and provider response bodies.

Send unpatched security issues by email instead of opening a public issue. Billing, quota, account recovery, and provider data-retention questions need to be handled by the corresponding service provider.
